# 모험단 키우기

> **모험단 키우기**는 **AFK: 새로운 여정**을 레퍼런스로 제작한 3D 방치형 RPG입니다.
> 최대 5명의 영웅으로 파티를 구성하고 전략적으로 배치하여 자동 전투 스테이지를 진행하며, 필드 탐험과 퀘스트를 통해 다양한 콘텐츠를 수행합니다.
> 전투와 방치 보상으로 획득한 재화를 활용해 영웅, 레벨 공명, 클래스 장비를 성장시키고 더 높은 스테이지와 콘텐츠에 도전하는 것을 핵심 플레이 구조로 구성했습니다.

## 핵심 플레이 루프

```text
영웅 획득 및 성장
        ↓
파티 편성 및 전략 배치
        ↓
스테이지 자동 전투
        ↓
스테이지 / 방치 보상 획득
        ↓
영웅 · 공명 · 장비 성장
        ↓
상위 스테이지 도전
        ↓
보상 효율 증가
```

스테이지 전투 외에도 필드를 직접 탐험하며 퀘스트, 상자, 필드 적 등의 콘텐츠와 상호작용할 수 있도록 구성했습니다.

# 구현 기능

## 1. 전략 배치
* 최대 5명의 영웅을 전투에 편성
* 전투 시작 전 지정된 슬롯에 영웅 배치
* 배치 / 해제 상태를 영웅 카드 UI와 실시간 동기화
* 영웅이 배치되지 않은 상태에서 전투 시작 방지
* 저장된 배치 상태 복원

---

## 2. 자동 전투
* 적 자동 탐색
* 공격 가능 거리까지 자동 이동
* 기본 공격 자동 실행
* 액티브 스킬 자동 사용
* 영웅 역할 및 공격 사거리에 따른 전투
* 승리 / 패배 판정
* 일반 전투와 필드 적 전투 흐름 분리

전투 화면에서는 현재 참여 중인 영웅의 HP와 초상화 HUD 및 영웅별 DPS 정보를 확인할 수 있습니다.

---

## 3. 스테이지

* CSV 기반 스테이지 데이터 관리
* 스테이지별 적 및 맵 구성
* Act별 몬스터 데이터 분리
* 스테이지 클리어 시 다음 스테이지 개방
* 최고 클리어 스테이지 저장
* 승리 / 패배 결과 UI
* 다음 스테이지 / 재도전 / 필드 복귀 흐름 분리
* 일반 / 보스 / 필드 보스 전투 지원

---

## 4. 자동 스테이지

* 스테이지 자동 연속 진행
* 자동 전투 중 현재 스테이지 정보 표시
* 자동 진행 중단 기능
* RenderTexture 기반 3D 전투 프리뷰
* 프리뷰 전용 캐릭터 공격 / 피격 애니메이션

자동 스테이지의 3D 전투 화면은 실제 전투 로직과 분리된 프리뷰 전용 연출로 구성했습니다.

---

## 5. 필드 탐험

* 쿼터뷰 기반 필드 이동
* Virtual Pad 기반 캐릭터 조작
* 필드 청크 스트리밍
* 미니맵 및 월드맵
* 월드맵을 통한 지역 이동
* 필드 적 상호작용 및 전투 진입
* 상자 / 보상 오브젝트 상호작용
* 전투 종료 후 기존 필드 위치 복귀
* 플레이어 마지막 위치 저장 및 복원
* 획득한 상자 및 처치한 필드 적 상태 저장

필드 적 전투는 기존 스테이지 전투 시스템을 재사용하지만 일반 스테이지 진행도와는 별도로 관리합니다.

## 6. 영웅 성장

* 레벨별 성장 비용 ScriptableObject 데이터화

* 최대 레벨 처리

## 7. 레벨 공명

* 공명 슬롯 영웅 배치 / 해제

## 8. 장비 / 인벤토리

* 클래스별 공유 장비 시스템
* Weapon / Hands / Accessory / Head / Body / Legs 6부위 구성
* 클래스별 장착 장비 관리
* 장비 자동 장착
* 더 높은 CraftLevel 장비 우선 장착
* 장비 세트 효과
* 동일 장비를 인벤토리에서 수량 단위로 묶어 표시

* 미장착 장비 일괄 분해

장비 데이터는 CSV를 원본으로 관리하며 Editor Import 기능을 통해 `EquipmentSO`와 `ItemDatabase`에 반영할 수 있도록 구성했습니다.

## 15. 저장 / 로드
JSON 기반 로컬 저장 시스템을 사용합니다.
저장 대상은 다음과 같습니다.

* 영웅
* 재화
* 장비 및 인벤토리
* 장비 장착 상태
* 공명
* 스테이지 진행도
* 배치
* 방치 보상
* 가챠
* 업적
* 퀘스트
* 상점
* 플레이어 위치
* 필드 오브젝트
* 옵션

일반 플레이 중 저장은 UniTask 기반 비동기 방식으로 처리하고 JSON 직렬화 및 파일 쓰기를 ThreadPool에서 수행합니다.
저장 중 데이터 변경으로 인한 불일치를 방지하기 위해 `GameSaveDataSnapshot`을 사용하며, 앱 종료 및 백그라운드 전환 시에는 저장 완료를 보장하기 위해 즉시 저장 방식을 사용합니다.
